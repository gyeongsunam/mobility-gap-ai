# 모두의 카드가 닿지 않는 곳: ‘강요된 자동차 의존’ 400m 격자 진단

**AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전**(한겨레 × 재단법인 숲과나눔, 2026) 출품 분석 코드.

대중교통 보행권 밖에 살면서 의원이나 생활편의시설까지 걸어서도 닿지 않는 사람, 곧 **차 없이는 생활이 불가능한 ‘자동차 필수 거주 인구’**를 전국 15만여 개 400m 생활격자(H3 res 8)에서 사람 단위로 진단하고, 그들이 치르는 비용(탄소와 고령운전 위험)과 받지 못하는 혜택(모두의 카드)을 결합해 정책 사각지대를 드러낸다.

## 핵심 결과 (2026년 9월 기준)

| 지표 | 값 |
|---|---|
| 대중교통(버스 400/800m, 철도 800m) 보행권 밖 인구 | **476만 명 (9.3%)** |
| 자동차 필수 거주 인구 (그중 생활필수시설도 보행 1km 밖) | **232만 명 (4.5%)**, 인구배분 방식에 따라 232~296만 |
| 그중 65세 이상 / 75세 이상 | 66만 명 / 28만 명 |
| 특별지원지역 vs 수도권: 자동차 필수 비율 / 1인당 모두의 카드 환급 | 7.7배 / 1/18 |
| 자동차 필수 비율 5분위 vs 1분위: 1인당 승용 CO₂ / 고령운전자 사고 사망률 | 1.8배 / 5.0배 |

자세한 수치와 그림은 `outputs/`와 보고서(`report/`)에 있고, 모든 값은 아래 한 줄로 재현된다.

## 재현 방법

```bash
pip install -r requirements.txt
python run_all.py                  # 원자료 내려받기부터 보고서 PDF까지 전체 실행(약 15~20분)
python run_all.py --skip-download  # 원자료를 이미 받았을 때
```

- PDF 조판에는 로컬 Google Chrome(Playwright `channel="chrome"`)을 쓴다.
- 원자료는 모두 로그인이나 API 키 없이 공개된 경로에서 받는다(`scripts/download_data.py`). 시군구 통계 정제본은 `data/raw/stats/tidy/`에 포함.

## 방법 요약

- **자동차 필수 거주 인구** = Σ 격자 인구 × (1 − 대중교통 커버율) × 𝟙[1차의료(의원, 보건기관) 또는 생활편의시설(편의점, 마트)이 보행 1km 밖]
- 커버 기준은 국토교통부 「대중교통 최소서비스 수준 조사」와 동일(버스 도시지역 400m, 녹지와 비도시 800m, 철도 800m), 보행거리=직선×1.3, 용도지역은 격자 인구밀도로 근사.
- 검증: 공식 2025 최소서비스 부족 비율과 시도 순위 상관(제주 제외), 좌표 대체 오차(4개 시도 복원 실험), 우회계수 1.0~1.4, 인구배분 3방식.
- 한계: 운행빈도(전국 정류장별), 실제 보행망, 용도지역은 공개자료 제약으로 근사. 시군구 수준 관계는 연관이며 인과가 아님.

## AI 활용 고지

- 분석 AI: LightGBM + TreeSHAP, 이중 머신러닝(DML), K-means.
- 생성형 AI: Claude Code(Anthropic)를 코드 작성과 검토, 자료 조사, 초안 교정에 사용했다. 모든 수치는 코드로 다시 계산해 확인했다.
